# Security review

The Python planner accepts only `lab.*` identities and does not connect to any directory. The Conditional Access template checker rejects enforcement, broad scope and missing emergency exclusion; it reads a placeholder JSON file and performs no Graph request. The Graph sample only reads users and rejects an unexpected tenant context. Live rollout must constrain sync OU scope, protect sync credentials/tier 0 host, avoid broad Graph permissions, monitor privileged roles and emergency sign-ins, and use report-only CA before enforcement. Microsoft notes report-only policies are evaluated but do not enforce access; emergency access exclusions matter when restrictive policies are enforced. No tenant security setting was changed. [Microsoft emergency access guidance](https://learn.microsoft.com/en-us/entra/identity/role-based-access-control/security-emergency-access).
